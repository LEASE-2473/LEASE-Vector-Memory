# LEASE Vector Memory

面向 SillyTavern 的行级冷热记忆表格与直接向量检索扩展。

> 本项目基于 [gaigai315/ST-Memory-Context](https://github.com/gaigai315/ST-Memory-Context) 修改，保留原项目贡献者署名并遵循其 README 声明的 MIT License。本项目由 LEASE 独立维护，不代表原作者立场或获得其背书。详见 [ATTRIBUTION.md](ATTRIBUTION.md)。

## 核心模型

- 七张详情表由批量填表 AI 维护；第八张“手工记忆”只允许用户编辑。
- 每张表使用独立、永不复用的稳定 ID：`R1、R2……`。
- `insertRow(表号, {...})` 自动生成 R 编号；更新和删除必须传入 R 编号。
- 白色热行直接进入日常剧情请求；绿色冷行只通过向量召回；锁定热行直接注入但对填表 AI 完全不可见。
- 主线和支线默认保留最近 3 行为热记忆，较旧行仅在 Embedding 成功后转绿；其他表默认不开启自动降冷。
- 批量填表若引用冷行、锁定行、不存在的 R 编号或手工记忆，整批事务拒绝，绝不部分写入。

## 向量记忆

- 每一行天然是一个完整切片，向量文本包含表名、R 编号、列名、完整单元格、标签和来源楼层。
- 每个聊天使用独立冷记忆系统书，条目按“表号 + R 编号”维护。
- 默认最多召回 20 条，不使用时间衰减；很久以前但语义相关的记忆拥有同等机会。
- “向量记忆区”明确分为“当前聊天记忆库 / API 设置 / 知识书管理”三页；知识书管理统一展示并启停聊天冷记忆书与外部知识书。
- 主表每行固定显示“转冷/转热、锁定/解锁”，工具栏另提供批量“显隐/锁定”。
- 关闭向量总开关时禁止自动降冷并把已有冷行恢复为白色，回到所有表格行直接注入的普通记忆表格模式。
- 隐藏持久化数据库名为 `LEASE_Vector_Memory_Database`。

## 注入与隔离

- 默认注入点是预设/System/世界书之后、历史聊天之前；显式设置深度时覆盖默认锚点。
- 调试面板显示最终插入索引、角色、热行数、冷召回数和实际请求消息。
- 插件 ID 为 `lease_vector_memory`，存储使用全新 `lvm_` 命名空间，不自动读取旧插件数据。
- 可通过“导入”显式迁移旧 LEASE Memory Context 导出文件：忽略总结表和旧绿色状态，先全部转白，再按当前 X 安全降冷。
- 外部向量书继续通过向量管理界面单独导出、导入。

## 已删除

- 记忆总结表、总结控制台、自动总结、总结提示词和总结进度。
- “详细表 → AI 总结 → 总结向量化”链路。
- 批量填表对冷行、锁定行与手工记忆的读取或写入能力。
